# Phase 5: Proposal and Dashboard

Build the user-facing review experience for the Cynbit AI Pre-Sales Solution Architect.

## Objective

Present the analysis in a professional dashboard that helps a technical or business reviewer decide what to do next.

## Required sections

1. Project summary
2. Extracted requirements
3. Missing information and clarification questions
4. Recommended technology stack
5. Complexity and risk score
6. Effort and timeline range
7. Cost, quotation, and profit estimate
8. Assumptions and exclusions
9. Draft proposal
10. Human review actions: edit, request clarification, export, or mark for decision

## Proposal requirements

Generate a professional draft containing scope, deliverables, timeline, assumptions, exclusions, pricing estimate, risks, and next steps.

## UX constraints

- Make uncertainty visible.
- Never present an estimate as a guarantee.
- Keep technical explanations understandable.
- Allow reviewers to edit important values before export.

## Completion criteria

- A reviewer can understand the project in one screen flow.
- Outputs can be copied or downloaded.
- Warnings and assumptions are not hidden.
